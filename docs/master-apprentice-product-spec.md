# BURYAД — ТЗ: бытовой бурятский через цифровой Master–Apprentice

## Цель продукта
За 8–12 недель ежедневной практики дать начинающему/heritage learner возможность понимать простую бытовую бурятскую речь и отвечать в типичных домашних, гостевых, уличных и деревенских ситуациях.

Главный критерий — не число изученных карточек, а способность понять ситуацию без русского перевода и быстро сформулировать простой ответ.

## Принципы
1. Сцена важнее урока.
2. Сначала предмет/действие/контекст, затем бурятское слово; русский — аварийная помощь.
3. В одной сцене не больше 3–7 новых единиц.
4. 80–90% материала сцены должно быть уже знакомо после первых вводных шагов.
5. Новое слово проходит состояния: unseen → seen → recognized → active → automatic.
6. Существительные вводятся визуально; глаголы — действием; абстрактные слова — повторяющимся контекстом.
7. Фраза должна возвращаться в другой ситуации, а не только в той карточке, где была введена.
8. Грамматика — справочник и короткое объяснение уже знакомой конструкции, а не обязательный путь.
9. Непроверенные формы не масштабируются как канонические.
10. Главный экран отвечает на один вопрос: «Что мне сегодня сделать, чтобы начать говорить?»

## Информационная архитектура
### Главный путь
- Сегодня / Жить
- одна рекомендуемая бытовая сцена;
- затем короткое повторение слабых слов;
- затем один разговор;
- затем аудирование.

### Вторичные инструменты
- Слова — словарь и состояние слов;
- Глаголы — справочник;
- Грамматика — справочник;
- Курс — структурированный архив/дополнительная практика;
- Прогресс — разговорная способность, словарь, скорость ответа.

## Механики сцены
- observe: посмотреть + услышать;
- choose: выбрать правильный предмет/смысл;
- act: выполнить действие в реальном мире;
- respond: ответить голосом/текстом;
- identify: назвать предмет без русского;
- contrast: отличить два близких значения;
- transfer: та же единица в новой сцене;
- finish: короткая мини-беседа без русского.

## Словарный движок
Для каждого lexical item:
- id;
- lemma;
- Buryat form;
- Russian fallback meaning;
- part of speech;
- semantic domain;
- visual asset;
- audio asset;
- dialect/register metadata;
- quality status;
- exposures;
- recognitions;
- active recalls;
- last seen;
- next review;
- state.

Приоритет повторения:
1. active, но ошибается;
2. recognized, но не active;
3. давно не видел;
4. новое.

## Целевой словарь
Не гнаться за количеством.
- этап 1: 150–250 сверхчастотных бытовых единиц;
- этап 2: 500–700 активных;
- ориентир пассивного словаря после базового пути: 1000+.
Слова вводятся тематически, но повторяются межсценарно.

## Визуальная система
- единый художественный язык;
- тёплая бурятская домашняя атмосфера;
- современная жизнь, а не музейная этнография;
- узнаваемая Бурятия/Тунка там, где это уместно;
- предмет в кадре должен быть однозначно распознаваем;
- без текста внутри изображения;
- изображения генерируются после стабилизации сценария;
- временные emoji/placeholder разрешены только на этапе разработки.

## Аудио
До появления записей носителей:
- интерфейс честно показывает отсутствие verified audio;
- не выдавать русский/монгольский TTS за бурятский.
После записи:
- slow;
- natural;
- optional fast;
- speaker/dialect/source metadata.

## Прогресс
Главные показатели:
- recognized vocabulary;
- active vocabulary;
- automatic vocabulary;
- среднее время ответа;
- сценарии без русской подсказки;
- недельная бытовая компетенция.
XP и бессодержательные streak-механики не являются целью.

## Definition of Done для базовой версии
Пользователь может открыть сайт каждый день и без выбора методики пройти 20–30 минут практики. Он регулярно видит и слышит знакомую бытовую ситуацию, осваивает несколько новых слов без обязательного перевода, выполняет действия, самостоятельно отвечает, встречает слова повторно в других сценах и видит рост recognized/active vocabulary. Старые учебные разделы не мешают этому пути.
