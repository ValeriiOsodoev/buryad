# Исследовательские основания

## Частотность

База: Электронный корпус бурятского языка ИМБТ СО РАН (~3 млн словоупотреблений, морфологическая разметка около 85%), Universal Dependencies Buryat BDT и открытые учебные материалы. Для курса сырой рейтинг письменной частоты фильтруется по бытовой полезности, потому что письменный корпус не является чистым корпусом повседневной устной речи.

## Глагольные формы

В beginner-модуле используются три простых времени литературного бурятского:
- настоящее: `-на/-нэ/-но`;
- завершённое прошедшее: `-аа/-ээ/-оо` и фонетические варианты;
- будущее: `-ха/-хэ/-хо`.

Личные показатели: 1 ед. `-б`, 2 ед. `-ш`, 1 мн. `-бди`, 2 мн. `-т`, 3 мн. `-д`. Продукт отдельно допускает разговорные сокращения в упражнениях и не объявляет таблицу исчерпывающей системой всех аспектуально-временных форм языка.

## Видео

В MVP видео встраиваются официальным YouTube embed. Для открытых роликов без надёжно извлечённой эталонной расшифровки используется режим self-review: ученик записывает услышанное, сохраняет попытку и переслушивает. Это лучше, чем показывать выдуманную «правильную» транскрипцию. Когда для ролика подтверждён текст, поле `reference` в `videos.json` включает автоматическое сравнение.
